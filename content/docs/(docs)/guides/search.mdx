## Open it

Press **Ctrl K** (**⌘K** on a Mac) anywhere in Deplo. Clicking the search box
at the top of the sidebar does the same thing, and so does pressing **/**.

On a phone, the magnifier in the header opens it full screen.

---

## What it finds

Type a few letters and the palette searches everything at once. Case and
separators are ignored, so `better auth` finds `better-auth-docs`.

| Group                           | What it covers                                                   |
| ------------------------------- | ---------------------------------------------------------------- |
| Apps, Databases                 | Every app and database, by name, slug or id                      |
| Servers                         | Fleet machines, by name or address                               |
| Projects, Environments, Folders | The Overview's own structure                                     |
| Domains                         | A hostname, and the app serving it                               |
| Members                         | People on the team, by name or username                          |
| Roles                           | The team's roles, by name                                        |
| Cron jobs                       | Scheduled jobs, and what they run on                             |
| Templates                       | The one-click catalogue                                          |
| Pages                           | Every page in Deplo, including each app's own tabs               |
| Settings                        | Two-factor, passkeys, registries, cleanup and the rest           |
| Actions                         | Redeploy, Start, Stop, Reload, New app, New database, Add member |

You only ever see what you are allowed to see. The palette hides what your
Capabilities do not cover, and the server checks again when you act on it.

## Reach one app's page directly

Name a page and you get it in every app; name the app too and you get just that
one - without stepping into the app first:

| You type              | You get                                            |
| --------------------- | -------------------------------------------------- |
| `deployments`         | Deplo's own page, then **every app's Deployments** |
| `deplo variables`     | **deplo-web / Environment**                        |
| `gamewatcher domains` | **gamewatcher / Domains**                          |
| `main backups`        | **main / Backups**                                 |

These rows wear the app's own logo with the page's icon badged onto it, so a
page belonging to one app never reads as a setting of Deplo itself.

The page is matched on its description too, not only its name - which is why
`variables` finds the page Deplo calls **Environment**.

Only six show at once; **Show N more** opens the rest without leaving the
palette.

<Callout type="info">
  A word that names one of your apps is spent naming it. Typing `blog` gives you
  the app, not fourteen rows of its pages.
</Callout>

## Step into a resource

Pressing **Enter** on an app or a database does not leave the palette. It opens
that resource's own menu: its actions on top, then every page it has.

<Steps>
  <Step>Type part of the name and press **Enter** on the row.</Step>
  <Step>
    Pick an action - **Redeploy**, **Start**, **Stop**, **Reload** - or a page
    such as **Logs**, **Monitoring** or **Settings**.
  </Step>
  <Step>**Backspace** on an empty box steps back out. So does **Escape**.</Step>
</Steps>

<Callout type="info">
  Destructive actions are deliberately absent. Deleting an app, rebuilding a
  database or restoring a backup stays on the page that owns it, behind its own
  confirmation.
</Callout>

## Other teams

The palette searches every team you can reach, not only the active one. Hits
from where you are working come first; anything else lands under **Other
teams**, each row labelled with the team it belongs to.

Pressing **Enter** on one of those switches you to that team and opens the
page in a single step.

**Team settings count too.** Searching `roles` gives you the active team's Roles
page and one for every other team you reach - and the roles themselves are
searchable by name, so typing what a role is called opens it.

Teams you cannot enter right now - an unmet two-factor policy, for example -
contribute nothing rather than failing the search.

## Keys

| Key                 | What it does                                        |
| ------------------- | --------------------------------------------------- |
| **Ctrl K** / **⌘K** | Open or close the palette                           |
| **/**               | Open the palette (unless you are typing in a field) |
| **↑ ↓**             | Move through the results                            |
| **Enter**           | Open the row, or step into a resource               |
| **Backspace**       | Step back out of a resource, when the box is empty  |
| **Escape**          | Step back out, or close                             |
