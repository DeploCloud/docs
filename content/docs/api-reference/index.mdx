The Deplo API is a REST API. All requests and responses use JSON.

## Base URL

```
https://api.deplo.build/v1
```

## Authentication

<Callout type="warning" title="Keep your API key secret">
  Requests are authenticated with a bearer token in the `Authorization`
  header. Never expose an API key in client-side code.
</Callout>

```bash
curl https://api.deplo.build/v1/deployments \
  -H "Authorization: Bearer $DEPLO_API_KEY"
```
