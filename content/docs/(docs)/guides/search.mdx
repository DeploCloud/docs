## Open it

Press **Ctrl K** (**⌘K** on a Mac) anywhere in Deplo, press **/**, or click **Search** at the top
of the sidebar. On a phone, the magnifier in the header opens it full screen.

  src={`${basePath}/screenshots/search/01-palette.png`}

/>

With the box empty it lists Deplo's pages, with your last five picks in this team under
**Recent**.

## What it finds

Type a few letters and it searches everything at once. Case and separators are ignored, so
`better auth` finds `better-auth-docs`. You only see what you are allowed to see.

<Image
  src={`${basePath}/screenshots/search/02-results.png`}
  alt="The palette filtered by a query, apps, pages and settings together"
  width={1728}
  height={1080}
  className="w-full rounded-lg"
/>

| Group | Matches on |
| --- | --- |
| Apps | Name, slug or id |
| Databases | Name or id |
| Servers | Name or address |
| Projects, Environments, Folders | Name |
| Domains | The hostname. The row names the app serving it |
| Members | Name or username |
| Roles | Name or description |
| Cron jobs | Name, or the app or database it runs on |
| Templates | The one-click catalogue, by name |
| Navigation, Settings | Every page, **New app**, and settings such as two-factor and passkeys |

**Enter** opens the row's page and closes the palette: an app or a database opens on its Overview.
The palette never deploys, starts or stops anything. **Search the documentation**, at the bottom,
opens this manual in a new tab.

## Reach one app's page directly

Type a page name to get it for every app and database. Add the app's name to get only that one:

| You type | You get |
| --- | --- |
| `deployments` | Deplo's own page, then **every app's Deployments** |
| `deplo variables` | **deplo-web / Environment** |
| `gamewatcher domains` | **gamewatcher / Domains** |

- A page also matches on its description, which is why `variables` finds **Environment**.
- Six of these rows show at once. **Show N more** opens the rest.
- A word that names an app matches the app, not its pages: `blog` gives you the app.

## Other teams

The palette searches every team you can reach. The current team comes first; the rest are under
**Other teams**, each labelled with its team. **Enter** on one switches team and opens the page in
one step.

Team settings are included: `roles` gives you the Roles page of every team. Teams you cannot enter
right now, for example because they require two-factor, are skipped.

## Keys

**Ctrl K** / **⌘K** opens and closes the palette, **/** opens it unless you are typing in a field.
Inside it, **↑ ↓** move through the results, **Enter** opens the row and **Escape** closes.
