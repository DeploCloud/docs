Deplo has no standalone CLI binary. These three shell scripts, `install.sh`,
`install-agent.sh` and `uninstall.sh`, are the closest thing to one: what
each does, and every flag.

## `install.sh` - the platform

```bash
curl -fsSL https://raw.githubusercontent.com/DeploCloud/deplo/main/install.sh | bash
```

Configured entirely by environment variables in front of the command. See
[Environment variables](/reference/environment-variables) for the table.

<Callout type="info" title="Requires">
  Root, `curl`, `openssl`, and Docker Compose v2. Docker itself is
  installed if missing.
</Callout>

<Steps>
<Step>
### Preflight checks
</Step>
<Step>
### Install Docker
Installs Docker if absent, and enables the service.
</Step>
<Step>
### Write the address pools
Writes Docker's `default-address-pools`, never clobbering an existing one,
backing up the old file and validating the new one.
</Step>
<Step>
### Create the layout
Creates `/opt/deplo/{traefik,data,acme}`, the `deplo` network, and
`acme.json` at `0600`.
</Step>
<Step>
### Generate secrets
Generates secrets into `/opt/deplo/.env` at `0600`, **once**.
</Step>
<Step>
### Start Traefik
Writes and starts the Traefik stack, with a read-only socket proxy sidecar.
</Step>
<Step>
### Symlink the proxy
Symlinks `/var/lib/deplo-agent/traefik` to it, so the local agent manages
the panel's own proxy.
</Step>
<Step>
### Start Deplo
Writes and starts the Deplo stack: Postgres on an internal network, and the
control plane publishing `3000`.
</Step>
<Step>
### Enroll this machine
Waits up to two minutes for `/api/health`, then enrolls this machine as a
server.
</Step>
</Steps>

<Callout type="info" title="Re-running it is the update path">
  It detects `/opt/deplo/.env`, switches to update mode, and never rotates
  a secret. The last step failing is a warning, not a fatal error: the
  panel stays up and a re-run retries it.
</Callout>

## `install-agent.sh` - a server

```bash
curl -fsSL https://<deplo>/install-agent.sh | sudo bash -s -- <TOKEN> <URL> [FINGERPRINT]
```

<Callout type="warn" title="Always take this command from the dashboard">
  The copy in the repository has placeholders that the running instance
  substitutes with the release's per-architecture URL and its checksum,
  and it refuses to run unsubstituted.
</Callout>

<TypeTable
  type={{
    "$1": {
      type: "bootstrap token",
      description: "The one-time bootstrap token. Single-use, hashed at rest, about an hour.",
    },
    "$2": {
      type: "url",
      description: "The control plane's URL, http(s)://host[:port].",
    },
    "$3": {
      type: "certificate fingerprint (optional)",
      description:
        "Pins the control plane over HTTPS. Over plain HTTP the token authenticates the response instead.",
    },
  }}
/>

<TypeTable
  type={{
    DEPLO_AGENT_PORT: {
      type: "port",
      default: "9443",
      description: "Listen port.",
    },
    "DEPLO_STORAGE_ONLY=1": {
      type: "flag",
      description:
        "Backups only: no Docker, no Traefik, no shared network, and the unit is installed without the docker group.",
    },
    "DEPLO_BUILD_ONLY=1": {
      type: "flag",
      description: "Build only: Docker and address pools, no Traefik.",
    },
    "DEPLO_IMPORT_ONLY=1": {
      type: "flag",
      description:
        "Migration source: Docker must already exist, address pools untouched, no Traefik, no network, no backup store.",
    },
  }}
/>

<Steps>
<Step>
### Refuse unsubstituted placeholders
Refuses to run if the placeholders were not substituted.
</Step>
<Step>
### Install Docker
Installs Docker if absent, and applies the address pools.
</Step>
<Step>
### Pick the binary
Picks the binary by architecture, `linux/amd64` or `linux/arm64` only.
</Step>
<Step>
### Verify the checksum
**Verifies the SHA-256 and refuses to run an unverified binary.**
</Step>
<Step>
### Install the agent
Installs to `/usr/local/bin/deplo-agent` and creates `/var/lib/deplo-agent`
at `0700`, **deleting any existing certificate files** so a reinstall
genuinely re-enrolls.
</Step>
<Step>
### Install Traefik
Creates the `deplo` network and installs Traefik, unless one is running or
80 and 443 are taken.
</Step>
<Step>
### Write bootstrap.env
Writes `bootstrap.env` at `0600`, never on the command line.
</Step>
<Step>
### Start the service
Writes the systemd unit at `0600` and starts it.
</Step>
</Steps>

The agent then calls home, sends a certificate signing request, and
receives a signed certificate. **The control plane never connects to your
machine to set this up.**

Logs: `journalctl -u deplo-agent -f`.

## `uninstall.sh` - remove Deplo

<Tabs items={['Dry run', 'Full removal', 'Agent only', 'Purge data']}>
  <Tab value="Dry run">
    ```bash
    curl -fsSL https://<deplo>/uninstall.sh | sudo bash
    ```
    Prints every command it would run. Changes nothing.
  </Tab>
  <Tab value="Full removal">
    ```bash
    curl -fsSL https://<deplo>/uninstall.sh | sudo bash -s -- --yes
    ```
    Actually removes the control plane, the agent and everything Deplo
    labelled.
  </Tab>
  <Tab value="Agent only">
    ```bash
    curl -fsSL https://<deplo>/uninstall.sh | sudo bash -s -- --yes --agent-only
    ```
    Leaves the control plane in `/opt/deplo` alone. This is the flag in
    the command the dashboard prints for a server.
  </Tab>
  <Tab value="Purge data">
    ```bash
    curl -fsSL https://<deplo>/uninstall.sh | sudo bash -s -- --yes --purge-data
    ```
    Also deletes Deplo volumes, images Deplo built, the stacks directory
    and `/opt/deplo` itself, `.env` included. **Irreversible.**
  </Tab>
</Tabs>

<TypeTable
  type={{
    "--yes": {
      type: "flag",
      description: "Actually do it. Without it, everything is a dry run.",
    },
    "--agent-only": {
      type: "flag",
      description:
        "Leave the control plane in /opt/deplo alone. This is the flag in the command the dashboard prints for a server.",
    },
    "--purge-data": {
      type: "flag",
      description:
        "Also delete Deplo volumes, images Deplo built, the stacks directory and /opt/deplo itself, .env included. Irreversible.",
    },
    "--purge-backups": {
      type: "flag",
      description:
        "Also delete /data/backups. Separate from --purge-data because everything else can be rebuilt from these. Irreversible.",
    },
  }}
/>

One script, three jobs. By default it removes the control plane in
`/opt/deplo` (the panel, its Postgres, its Traefik), the agent, Deplo's
named containers, every container labelled as Deplo-managed, the `deplo`
network and `/var/lib/deplo-agent`. `--agent-only` stops at the agent. It
never touches Docker Engine, never rewrites `/etc/docker/daemon.json` (the
installer's backup stays as `daemon.json.deplo-bak`), and never touches a
container it did not label. Safe on a machine that was never a Deplo host,
and safe to run twice.

<Callout type="warn">
  **`--purge-data` deletes `/opt/deplo/.env`, and that holds
  `DEPLO_SECRET`.** Every backup artifact this instance wrote is encrypted
  with a key derived from it. Copy the file first if you may ever want to
  restore one.
</Callout>

The older `/uninstall-agent.sh` URL still works and always will: it serves
this same script with `--agent-only` already applied, so a command copied
into a runbook before `uninstall.sh` existed still means what it meant
then.

## Verifying before you pipe to a shell

Every one of these is a `curl | bash`. If that makes you uneasy, and it
reasonably might, download and read first:

```bash
curl -fsSL https://raw.githubusercontent.com/DeploCloud/deplo/main/install.sh -o install.sh
less install.sh
sudo bash install.sh
```

The agent installer is worth reading for a different reason: it is where
the checksum verification lives, and seeing it refuse an unverified binary
is more convincing than being told it does.
