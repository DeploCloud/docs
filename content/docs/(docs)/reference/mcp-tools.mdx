<Callout type="info" title="Beta">
This feature is currently beta/experimental and subject to change. It is
not recommended for production. Try it out and share your feedback on
[our GitHub](https://github.com/DeploCloud/deplo/issues).
</Callout>

The tools an AI agent gets from the [MCP server](/guides/mcp-server): **192** today, the number
changes with the product. `graphql_query` and `graphql_mutate` cover anything no other tool does.

- An agent sees only the tools its token can use.
- **Needs** is the capability the token must hold (**instance admin** is the token's instance admin
  bit).
- A **destructive** tool is where a good client asks you first.
