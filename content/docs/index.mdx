Deplo runs your apps on servers you own, and does the operations work for you: push a repo, pick a server, get a deployment, on your own infrastructure.

You give it a repository, a Docker image or a Compose file. It builds the code, starts the containers, points a hostname at them, gets the TLS certificate, keeps the logs, takes the backups and restarts what dies. The comparison is Vercel, Railway or Render, except the machine is yours and the bill is your hosting bill.

## Why Deplo

You should not have to learn Docker or SSH to deploy your own app. The big clouds figured out this experience years ago: push, and it's live, with someone else doing the operations. Deplo is that experience on hardware you own and a bill you control.

- **A VPS and a domain is enough.** The platform does the operator's job: builds, routing, TLS, databases, backups, monitoring, rollbacks.
- **No per-seat pricing, no build minutes, no vendor lock-in.** You pay your host, not Deplo.
- **The shell is an escape hatch, never a requirement.** It stays available for experts, and you get full value without ever opening it.
- **Deploy from anything.** A Git repo, a registry image, a Dockerfile, a Compose file, or a plain upload.
- **One-click templates**, teams with fine-grained capabilities, and any number of servers.
- **Every pull request gets its own preview URL**, and a rollback is instant, no rebuild.
- **Backups go where you already have storage.** An S3 bucket, or another server's disk you own.
- **A free working URL from the first deploy**, before you own a domain.

## How it works

Deplo is two programs and one rule: the control plane decides, the agent executes, and only the agent ever touches Docker.

<RequestFlowIllustration className="w-full max-w-md mx-auto h-auto not-prose" />

- **The control plane decides.** It renders the Compose file and the routing, resolves secrets, and never touches Docker or a host directly.
- **The server agent executes.** One Go binary per host, the only thing that runs Docker anywhere, reached over mutual TLS.
- **Traefik routes and issues the certificates. Postgres remembers**, the single source of truth.

The box running Deplo itself is just another server in the fleet, no special shortcut.

## What Deplo is not

- **Not a hosting provider.** You bring the server. Deplo never bills you for compute, seats or build minutes.
- **Not a DNS provider.** You keep your registrar. Deplo tells you which record to create and checks that it resolves.
- **Not Kubernetes.** The unit is a Docker container on a host you picked, not a scheduled pod. There is no cluster to operate.
- **Not a black box.** The rendered Compose file, the routing labels and the build logs are all readable from the dashboard.
