Use this for a wildcard, a private certificate authority, or a hostname that cannot complete an
HTTP challenge.

**Settings -> Servers -> the server -> Certificates.** Instance admins only.

- **It lives in that server's Traefik, and nowhere else.** Deplo keeps no copy: the list is read
  back from the host, and the private key is never shown again.
- **It needs the Traefik Deplo installed**, and Docker Compose 2.23.1 or newer on the server.
- **Installing restarts the proxy**, so every site on that server blinks for a few seconds.

## Install one

<Steps>
<Step>

### Add the pair

**Add certificate**, then paste both, as PEM:

- **Certificate**: the full chain, your certificate first and then the intermediates. Usually
  `fullchain.pem`.
- **Private key**: without a passphrase.

Then **Install certificate**. Deplo refuses an expired or not-yet-valid certificate, a key that
does not match, and a chain in the wrong order.

</Step>
<Step>

### Point the domain at it

Set the domain's **Certificate** to **Installed on the server**, then redeploy the app or
**Reload** it, which re-applies its domains without a rebuild.

</Step>
</Steps>

**Refresh** re-reads the list from the host. **Remove** deletes it there.

## Which domains use it

| Domain **Certificate** | Uses it? |
| --- | --- |
| **Installed on the server** | Yes. TLS on and no ACME resolver, so Traefik never tries to issue one. |
| **Let's Encrypt** or **Cloudflare** | Yes, when it covers the hostname: Traefik does not issue for a name its store already covers. |
| **None (no certificate)** | No. Plain HTTP. |

A new certificate that covers every name of an installed one replaces it. One that only overlaps
is kept alongside.

## Important limits

- **Nothing renews it.** The list counts down the last 21 days, then visitors get an expiry
  error. Put the renewal in your own calendar.
- **It is per server.** An app running on two machines needs it on both.

## Troubleshooting

- **"Deplo did not install the proxy"**: that server runs your own proxy. Install it there.
- **Installing fails with a config error**: Docker Compose on the server is older than 2.23.1.
- **The browser still sees a Let's Encrypt certificate**: the hostname is not in your
  certificate's domains, or the domain is not set to **Installed on the server**.
- **Traefik serves its own default certificate**: the certificate does not cover that hostname,
  or the app was not redeployed or reloaded.
- **It works on one app and not another**: the other app runs on a different server.

More in [Domains and TLS troubleshooting](/troubleshooting/domains-and-tls).
