Certificates you installed yourself: wildcards, a company CA, or a name
no HTTP challenge can reach.

---

## How it works

**Settings -> Servers -> the server -> Certificates.** They live in that
host's Traefik stack. Deplo keeps no copy, and the private key has no
read path. **Nothing renews them.**

See [Custom certificates](/advanced/custom-certificates) for how to
install one.

---

## If it does not work

See [Domains and TLS](/troubleshooting/domains-and-tls) for certificate
warnings and related symptoms.
