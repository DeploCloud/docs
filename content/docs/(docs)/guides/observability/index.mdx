title: Observability
description: Logs, metrics, alerts, a shell into a container, and scheduled jobs.
---

Five ways to see what your apps are doing right now. Everything comes from the
agent on the server, over the same secure connection Deplo uses for everything
else. No SSH, no exposed Docker socket.

**Logs** - live container output, and the output of every build.
[Learn more ->](/guides/observability/logs)

**Monitoring** - CPU, memory, disk and network, with a short history.
[Learn more ->](/guides/observability/monitoring)

**Notifications and alerts** - get told when something happens.
[Learn more ->](/guides/observability/notifications-and-alerts)

**Console** - look inside a running container.
[Learn more ->](/guides/observability/console)

**Cron jobs** - run a command on a schedule, inside a container.
[Learn more ->](/guides/observability/cron-jobs)
