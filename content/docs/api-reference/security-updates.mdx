Deplo reads the packages of every image it runs and matches them against OSV.dev every 6 hours and right after a deploy. Only the app's own dependencies and the software an image ships are returned. Read `groups`: one entry per package of the app's, or per image, the way the dashboard counts them, with `counted` saying whether it is in `count` and every advisory inside. `updates` keeps one row per advisory. An image's `update` appears only once its newer build was read and found to have the fix. Every call on one app or database names exactly one `appId` or `databaseId`.

## Reading

### `securityUpdates`

Any signed-in principal. Returns [`SecurityUpdates`](/api-reference/types/objects#securityupdates).

The security updates of one app (`appId`) or managed database (`databaseId`) in the active team. Null when it is out of reach or the instance turned checks off.

| Argument | Type | Description |
| --- | --- | --- |
| `appId` | `ID` |  |
| `databaseId` | `ID` |  |

```graphql
query {
  securityUpdates(appId: "prj_9f1c2ab7d3e4f5a6") {
    checkedAt
    checking
    count
    exploited
  }
}
```

### `securityUpdatesOverview`

Any signed-in principal. Returns [`[SecuritySubject!]`](/api-reference/types/objects#securitysubject).

Every app and database in the active team with security updates to apply, most urgent first. Empty when the instance turned checks off.

```graphql
query {
  securityUpdatesOverview {
    id
    slug
    name
    count
  }
}
```

## Ignoring

### `ignoreSecurityUpdate`

Needs `ignore_security_updates`. Returns `Boolean`.

Set advisories aside on one app or database for 30, 90 (default) or 180 days, with an optional reason. They stay listed but stop counting and alerting until then; a new advisory still shows. Recorded in Activity.

| Argument | Type | Description |
| --- | --- | --- |
| `appId` | `ID` |  |
| `databaseId` | `ID` |  |
| `days` | `Int` |  |
| `reason` | `String` |  |
| `vulnIds` | `[String!]!` | The advisory ids (`vulnId`) to act on: every advisory of one package, usually. |

```graphql
mutation {
  ignoreSecurityUpdate(vulnIds: ["GHSA-xvch-5gv4-984h"])
}
```

### `unignoreSecurityUpdate`

Needs `ignore_security_updates`. Returns `Boolean`.

Count and alert on advisories set aside with ignoreSecurityUpdate again. Recorded in Activity.

| Argument | Type | Description |
| --- | --- | --- |
| `appId` | `ID` |  |
| `databaseId` | `ID` |  |
| `vulnIds` | `[String!]!` | The advisory ids (`vulnId`) to act on: every advisory of one package, usually. |

```graphql
mutation {
  unignoreSecurityUpdate(vulnIds: ["GHSA-xvch-5gv4-984h"])
}
```

## The instance switch

### `securityUpdatesStatus`

Instance admin only. Returns [`SecurityUpdatesStatus`](/api-reference/types/objects#securityupdatesstatus).

```graphql
query {
  securityUpdatesStatus {
    enabled
    failingSince
    lastCheckedAt
  }

```

### `setSecurityUpdatesEnabled`

Instance admin only. Returns [`SecurityUpdatesStatus`](/api-reference/types/objects#securityupdatesstatus).

Turn security update checks on or off for the whole instance. On, Deplo sends OSV.dev the name and version of each package the team's images contain, never an app name or anything that identifies this Deplo. Recorded in Activity.

| Argument | Type | Description |
| --- | --- | --- |
| `enabled` | `Boolean!` |  |

```graphql
mutation {
  setSecurityUpdatesEnabled(enabled: true) {
    enabled
    failingSince
    lastCheckedAt
  }
}
```
