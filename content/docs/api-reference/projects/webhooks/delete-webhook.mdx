```
DELETE /v1/projects/:id/webhooks/:webhookId
```

```bash
curl -X DELETE https://api.deplo.cloud/v1/projects/prj_4b91aa/webhooks/wh_2ea910 \
  -H "Authorization: Bearer $DEPLO_API_KEY"
```

Returns `204 No Content` on success.
