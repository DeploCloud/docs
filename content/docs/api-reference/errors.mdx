---
title: Errors
description: Error response shape and status codes.
---

Errors are returned as JSON with a consistent shape:

```json
{
  "error": {
    "code": "deployment_not_found",
    "message": "No deployment with id dep_8f2a1c.",
    "status": 404
  }
}
```

## Status codes

<TypeTable
  type={{
    "400": {
      description: "Malformed request body or query parameters",
      type: "bad_request",
    },
    "401": {
      description: "Missing or invalid API key",
      type: "unauthorized",
    },
    "403": {
      description: "API key valid, but not authorized for this resource",
      type: "forbidden",
    },
    "404": {
      description: "Resource does not exist, or you don't have access to it",
      type: "not_found",
    },
    "429": {
      description: "Rate limit exceeded, see Retry-After header",
      type: "rate_limited",
    },
    "500": {
      description: "Something went wrong on Deplo's end",
      type: "internal_error",
    },
  }}
/>

<Callout type="error" title="Retrying 5xx errors">
  Retry with exponential backoff. Never retry a `4xx` response without
  changing the request, it will fail again.
</Callout>
