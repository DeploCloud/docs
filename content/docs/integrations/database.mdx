title: Database

icon: Database
---

```bash
deplo db create --name main --region fra1
```

This provisions a managed Postgres instance and injects `DATABASE_URL`
into your project's environment variables automatically.

## Branching

<Callout type="idea" title="Database branches">
  Every preview deployment can get its own copy-on-write database branch,
  so migrations in a pull request never touch production data.
</Callout>

```bash
deplo db branch create --from main --name pr-142
```

## Connection pooling

<Callout type="info">
  Deplo runs a connection pooler in front of every database by default.
  Serverless and edge functions should use the pooled connection string
  (`DATABASE_URL`), long-running processes can use the direct one
  (`DATABASE_URL_DIRECT`).
</Callout>

<Callout type="error" title="Connection limits">
  The direct connection string has a hard cap of 20 concurrent connections.
  Exceeding it fails new connections rather than queueing them, use the
  pooled URL from serverless functions.
</Callout>
