Build settings and rollbacks apply to apps Deplo builds: from a repository or an uploaded archive.
A Docker image app or a pasted Compose app has neither.

**Build settings**: the build method, its commands, and the port the app listens on. Most apps
never change them.
[Learn more ->](/guides/releases/build-settings)

**Automatic deployments**: a push to the branch, a new tag, or a call to the deploy hook URL.
[Learn more ->](/guides/releases/automatic-deployments)

**Rollbacks**: back to an image that already worked, in seconds and without a rebuild, or by
rebuilding an older commit. A rollback does not stop future deploys, so turn off deploy on push
first if the branch itself is broken.
[Learn more ->](/guides/releases/rollbacks)
