Deplo runs builds in isolated, ephemeral containers. Each build gets a fresh
filesystem, but a persistent cache keyed by your lockfile.

<Callout type="idea" title="Cold vs. warm builds">
  The first build on a new branch is always cold (no cache). Every build
  after that on the same branch is warm, typically 3 to 8 times faster.
</Callout>

## Overriding the build command

By default Deplo infers the build command from your framework preset. To
override it, add a `deplo.json` at the project root:

```json title="deplo.json"
{
  "build": "bun run build",
  "output": ".next",
  "installCommand": "bun install --frozen-lockfile"
}
```

<Callout type="error" title="Common mistake">
  Don't set `output` to a directory your build command doesn't actually
  produce, deployment will fail at the upload step with `ENOENT`.
</Callout>
