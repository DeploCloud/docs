---
title: Environment Variables
description: Store config and secrets per environment.
icon: KeyRound
---

```bash
deplo env set KEY value --env production
deplo env list --env production
deplo env rm KEY --env production
```

## Plaintext vs. secret

<Tabs items={['Plaintext', 'Secret']}>
<Tab value="Plaintext">

Visible in the dashboard and in `deplo env list`. Use for non-sensitive
config like feature flags or public URLs.

```bash
deplo env set NEXT_PUBLIC_API_URL https://api.example.com --env production
```

</Tab>
<Tab value="Secret">

Encrypted at rest, write-only after creation, never shown again in the
dashboard or CLI output.

```bash
deplo env set DATABASE_URL "postgres://..." --env production --secret
```

</Tab>
</Tabs>

<Callout type="error" title="Secrets in preview deployments">
  Preview deployments inherit the `staging` environment by default. Never
  store production secrets under `staging` if your previews are public.
</Callout>

<Callout type="idea">
  Bulk-import variables from a `.env` file with `deplo env pull` /
  `deplo env push`.
</Callout>
