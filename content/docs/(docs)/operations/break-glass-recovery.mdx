Use this only when the dashboard cannot restore access. Run the command as
root on the host that runs the control plane.

<Callout type="warn" title="Emergency access">
These commands bypass capability checks and do not appear in **Activity**.
Root on the control-plane host is the only credential they require.
</Callout>

## The `deplo` command

`install.sh` puts it at `/usr/local/bin/deplo`. Run it over SSH on the host:

```bash
deplo
```

| Command | What it does |
| --- | --- |
| `deplo recover` | Break-glass account and address recovery, below |
| `deplo logs [lines]` | Follow the control plane's logs |
| `deplo restart` | Restart the control plane |
| `deplo update` | Re-run the installer to the latest version |

<Callout type="info">
  Updating is normally a button - **Settings -> Deplo -> Updates**. `deplo update` is the fallback
  for when the dashboard is what is broken. See [Upgrade](/operations/upgrade).
</Callout>

## Recovery commands

```bash
deplo recover
```

<Steps>

<Step>

### See the accounts

```bash
deplo recover list
```

Lists every account with its username, email, and admin, owner, or suspended state.

</Step>

<Step>

### Take the account back

```bash
deplo recover password ada
deplo recover password ada -
```

The first prompts for the new password. The second generates one and prints it.
**Every session for that account is signed out.**

</Step>

<Step>

### Restore ownership or access

```bash
deplo recover owner ada
deplo recover admin ada
deplo recover unsuspend ada
```

`owner` transfers ownership and restores admin and active status. The previous
owner keeps their admin flag until you remove it in **Settings -> Users**.

</Step>

</Steps>

## When the address is what broke

If the panel's domain, DNS, or certificate is broken, restore its address from
the control-plane host:

```bash
deplo recover panel-address deplo.example.com
deplo recover panel-address -
```

`-` restores the generated `deplo-<hex>.nip.io` address. Restart the control
plane afterwards so install commands and links use the restored address:

```bash
deplo restart
```

To correct a server address that was mistyped:

```bash
deplo recover server-address eu-main-1 10.0.0.7
deplo recover server-address eu-main-1 10.0.0.7 9443
```

This skips the normal reachability check, so it also works when the panel
cannot currently reach the server.

## From a source checkout

Running Deplo from a checkout instead of the image? The same tool is a package script, and the
subcommands are identical:

```bash
bun run recover owner ada
```
