Only for when the dashboard cannot restore access. Run these as root on the machine Deplo runs on.

<Callout type="warn" title="Emergency access">
These commands bypass capability checks, and the account commands leave no trace in **Activity**.
Root on that machine is the only credential they need.
</Callout>

## The `deplo` command

`install.sh` puts it at `/usr/local/bin/deplo`.

| Command | What it does |
| --- | --- |
| `deplo recover` | Reset a password, restore an account or an address, below |
| `deplo logs [lines]` | Follow the control plane's logs |
| `deplo restart` | Restart the control plane |
| `deplo update` | Update to the newest version, canary too if turned on. See [Update](/operations/update#if-the-panel-cannot-update-itself) |

## When someone is locked out

<Steps>
<Step>
### See the accounts

```bash
deplo recover list
```

Every account with its username, email, and admin, owner or suspended state.
</Step>

<Step>
### Reset a password

```bash
deplo recover password ada
deplo recover password ada -
```

The first prompts for the new password (8 characters at least); `-` generates one and prints it.
**Every session of that account is signed out.**
</Step>

<Step>
### Restore ownership or access

```bash
deplo recover owner ada
deplo recover admin ada
deplo recover unsuspend ada
```

`owner` makes `ada` the instance owner, an instance admin and not suspended. The previous owner keeps
their admin flag until you remove it in **Settings -> Users**.
</Step>
</Steps>

## When the address is what broke

If the panel's domain, DNS or certificate is broken:

```bash
deplo recover panel-address deplo.example.com
deplo recover panel-address -
```

`-` restores the generated address (like `deplo-cb00710a.deplo.site`) and turns the backup address
back on. Nothing moves yet: Deplo makes the move as it starts, and says so:

```text
panel: moves to deplo.example.com (https)
Deplo makes the move as it starts: run `deplo restart` now, then open the new address.
```

```bash
deplo restart
```

Then open the new address. **Activity** records the move. Moving anywhere but a
[Cloudflare Tunnel](/operations/cloudflare-tunnel)'s own address also turns the tunnel off and deletes
it in Cloudflare, while its saved token still works.

To fix a mistyped server address, the one its apps' generated addresses are built from:

```bash
deplo recover server-address eu-main-1 10.0.0.7
```

It saves the address as given and checks nothing.

## From a source checkout

Running Deplo from a checkout instead of the image? Same subcommands, as a package script:

<Tabs items={['bun', 'pnpm', 'npm']}>
<Tab value="bun">

```bash
bun run recover owner ada
```

</Tab>
<Tab value="pnpm">

```bash
pnpm run recover owner ada
```

</Tab>
<Tab value="npm">

```bash
npm run recover -- owner ada
```

</Tab>
</Tabs>
