---
title: Quickstart
description: Your first deployment on Deplo, in under 5 minutes.
---

<Steps>
<Step>

### Install the CLI

See [Installation](/getting-started/installation) for every platform and
package manager.

```bash
curl -fsSL https://deplo.build/install.sh | sh
```

</Step>
<Step>

### Log in

```bash
deplo login
```

This opens your browser to authenticate the CLI with your Deplo account.

</Step>
<Step>

### Deploy

From the root of your project:

```bash
deplo up
```

Deplo detects your framework, runs the build, and publishes a public
preview URL in seconds.

</Step>
<Step>

### Promote to production

```bash
deplo promote
```

Or click **Promote** on the deployment in the dashboard.

</Step>
</Steps>

<Callout type="success" title="That's it">
  You now have a live deployment. See [Core Concepts](/core-concepts/deployments)
  to understand how builds, previews, and rollbacks fit together.
</Callout>
