title: App Router
description: Server components, route handlers, and streaming on Deplo.
---

The App Router's server-first model maps directly onto Deplo's Node
runtime, no extra configuration is needed.

## Server components

React Server Components render on request in the same Node runtime as your
route handlers. Data fetched inside a server component is never sent to the
client bundle.

## Route handlers

`app/api/**/route.ts` and any `app/**/route.ts` file deploy as regular
serverless functions:

```ts title="app/api/hello/route.ts"
export async function GET() {
  return Response.json({ message: "Hello from Deplo" });
}
```

<Callout type="idea">
  Route handlers cold-start in under 100ms on Deplo, most requests never see
  a cold start once a function has been warm for a few minutes.
</Callout>

## Streaming

`loading.tsx` and `<Suspense>` boundaries stream progressively over HTTP,
Deplo's edge network passes chunks through without buffering the full
response.

<Callout type="warning" title="Streaming and Edge runtime">
  Streaming responses from `export const runtime = 'edge'` route handlers
  are capped at 30 seconds of total duration.
</Callout>
