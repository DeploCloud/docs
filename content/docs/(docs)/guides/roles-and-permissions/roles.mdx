---
title: Build a role
description: Name a set of capabilities, tick the ones it needs, and every member holding it updates at once.
---

import Image from "next/image";
import { basePath } from "@/lib/base-path";

<Steps>
<Step>

### Open roles settings

Open **Settings -> Roles**.

<Image
  src={`${basePath}/screenshots/roles/01-roles-list.png`}
  alt="Every role of the team with its permission count and how many members hold it"
  width={1728}
  height={1080}
  className="w-full rounded-lg"
/>

</Step>
<Step>

### Start a new role

Click **New role**. Choose to start blank or from an existing role.

</Step>
<Step>

### Name it

Give it a **Name** and a **Description**.

</Step>
<Step>

### Tick capabilities

Use the search box or browse by category. Each category header has a **Select all** /
**Unselect all** toggle for the visible items. `view` is always ticked.

<Image
  src={`${basePath}/screenshots/roles/02-role-detail.png`}
  alt="One role open: name, two-factor requirement and the capabilities it grants"
  width={1728}
  height={1080}
  className="w-full rounded-lg"
/>

</Step>
<Step>

### Check the sensitive ones

Capabilities marked **Sensitive** deserve a second look: deleting things, opening consoles,
revealing secrets, managing tokens, managing roles.

</Step>
<Step>

### Optionally require two-factor

Turn on **Require two-factor authentication** for this role if needed.

</Step>
<Step>

### Save

Save.

</Step>
</Steps>

**Reset to default** restores a built-in role. **Delete role** removes one you created.

You cannot grant what you do not have: those capabilities show as **Out of reach**.
