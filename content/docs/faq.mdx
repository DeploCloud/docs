<Accordions type="single">
  <Accordion title="How is Deplo different from other cloud providers?">
    No infrastructure to configure. Connect a repository, Deplo detects the
    framework, builds it, and gives every branch its own preview URL. There's
    no load balancer, VM, or Kubernetes cluster to set up.
  </Accordion>
  <Accordion title="Can I use my own domain?">
    Yes, see [Custom Domains](/core-concepts/custom-domains). TLS
    certificates are issued and renewed automatically.
  </Accordion>
  <Accordion title="What happens if a build fails?">
    The previous production deployment keeps serving traffic unchanged. A
    failed build never takes your site down, see [Deployments](/core-concepts/deployments).
  </Accordion>
  <Accordion title="Does Deplo support monorepos?">
    Yes. Point a project at a subdirectory with `--root <path>` when linking,
    each project in the monorepo gets independent deployments and
    environment variables.
  </Accordion>
  <Accordion title="Is there a free tier?">
    Yes, the Hobby plan includes unlimited preview deployments and one
    production project at no cost.
  </Accordion>
</Accordions>
