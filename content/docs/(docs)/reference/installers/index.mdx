Choose the script that matches the host and action. Deplo has three shell
scripts:
[`install.sh`](/reference/installers/install),
[`install-agent.sh`](/reference/installers/install-agent) and
[`uninstall.sh`](/reference/installers/uninstall).

| Script | Use it for |
| --- | --- |
| [`install.sh`](/reference/installers/install) | Install or update the control plane and its local server |
| [`install-agent.sh`](/reference/installers/install-agent) | Add another server, build server, storage server, or migration source |
| [`uninstall.sh`](/reference/installers/uninstall) | Remove an agent or the whole Deplo installation |

## Inspect before running

Each command downloads a script and pipes it to Bash. Download it first if
you want to inspect the script or save it for review:

```bash
curl -fsSL https://deplo.build/install.sh -o install.sh
less install.sh
sudo bash install.sh
```

`install-agent.sh` also verifies the downloaded binary checksum before it
runs it.
