The role is picked when you add the server. It decides what the installer sets up on the host
and where the server appears in Deplo.

## Compare server roles

| Role | Docker | Traefik | Deploy target | Backup destination | In monitoring |
| --- | --- | --- | --- | --- | --- |
| **Everything** | yes | yes | yes | yes | yes |
| **Build only** | yes | no | no | no | yes |
| **Backups only** | no | no | no | yes | yes |
| **Migration source** | must exist already | no | no | no | no |

### Everything

The default, and what a single-machine install uses: Docker, Traefik on ports 80 and 443, the
shared `deplo` network, and Docker address pools sized for about 2,000 networks (Docker's own
default stops at about 31).

### Build only

For [build servers](/advanced/build-servers). Docker and the address pools, because it creates
networks while building, but no Traefik, because nothing is routed to it.

Pick the **Build** tile (Beta) when you add a server, or put `DEPLO_BUILD_ONLY=1` in front of the
agent installer. Its badge then reads **Build only**.

Any server but Backups only and a migration source can also be a
[build fallback](/advanced/build-servers#when-the-builder-is-down).

### Backups only

A storage box for backup artifacts: **no Docker**, no Traefik, no `deplo` network.

Backups are encrypted before they reach it, and it only gets the public half of each
destination's key, so **it holds artifacts it cannot read**.

Pick the **Backups** tile, or use `DEPLO_STORAGE_ONLY=1`. Its badge reads **Backups only**.

### Migration source

Created only by the [migration wizard](/migrations), never from the servers page.

- **Docker must already be there.** No address pools, no Traefik, no `deplo` network.
- **It is out of everything else**: deploy and build pickers, backup destinations, cleanup,
  monitoring and the fleet count. One team only.
- **It is the only server Deplo uninstalls itself from**, with one action on the servers page.
  Do that when the migration is done.
- **A [move from another Deplo](/migrations/move-from-another-deplo) needs none.** The
  installer refuses a machine whose agent belongs to another Deplo.

## Change a role later

**Settings -> Servers -> the server -> Advanced -> What this server is for**, then **Save**.
Instance admins only.

- **Leaving Everything** needs an empty server: move its apps and databases off first.
- **Build only back to Everything** has no Traefik: apps run but stay unreachable on their
  domains until you re-run the install command on the host.
- **A server installed as Backups only** has no Docker, so it stays Backups only until you
  re-run the install command.
- **A migration source** never changes role.

The role does not decide who may use the server. That is [team access](/operations/servers).
