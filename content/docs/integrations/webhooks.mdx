```bash
deplo webhooks add https://example.com/hooks/deplo --event deployment.ready
```

## Payload

```json
{
  "event": "deployment.ready",
  "deploymentId": "dep_8f2a1c",
  "project": "marketing-site",
  "branch": "main",
  "url": "https://marketing-site.deplo.app",
  "createdAt": "2026-08-25T10:32:00Z"
}
```

<Callout type="warning" title="Verify the signature">
  Every webhook request includes an `X-Deplo-Signature` header, HMAC-signed
  with your webhook secret. Always verify it before trusting the payload.
</Callout>
