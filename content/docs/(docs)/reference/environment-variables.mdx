## Variables read by `install.sh`

Written into `/opt/deplo/.env` and read by `docker compose --env-file`. Set
them before the install command.

The installer also honours `DEPLO_SKIP_NET_CHECKS=1`, `DEPLO_IMAGE`,
`DEPLO_TRACE`, `DEPLO_LOG_FILE`, and `DEPLO_DIR`. The agent installer accepts
`DEPLO_TRACE` and `DEPLO_LOG_FILE` too.

## Before you change one

<Callout type="warn" title="DEPLO_SECRET is permanent">
  Back up `/opt/deplo/.env`. See [Disaster recovery](/operations/disaster-recovery).
</Callout>

- **`DEPLO_SERVER_IP` must be a real, internet-reachable address.** Generated
  hostnames encode an IPv4 in hexadecimal and an IPv6 after `v6-`, so a
  private or loopback address produces URLs that only work from that machine.
- **A hostname in `DEPLO_PUBLIC_URL` cannot seed a `deplo.site` name**, so
  Deplo falls through to interface detection for the IP. Set
  `DEPLO_SERVER_IP` explicitly on a multi-homed box.
- **`DEPLO_DATA_DIR` is staging, not storage.** Nothing durable lives
  there.
- **Build-time placeholders exist in the Dockerfile** for the database URL
  and the secret. They never reach the runtime image and are not usable
  values.
