Every app starts from one of five sources. Pick the one that matches what you have, or start from
a template.

| Source | What it needs | Builds an image | Rollback |
| --- | --- | --- | --- |
| [GitHub](/guides/deploy/from-git) | A repository, connected once per team | yes | yes |
| [Git](/guides/deploy/from-git) (beta) | GitLab, Bitbucket, Gitea or any git server | yes | yes |
| [Docker image](/guides/deploy/docker-image) | An image reference | no, already built | no |
| [Upload](/guides/deploy/upload-code) | A compressed archive of the project | yes | yes |
| [Compose](/advanced/compose-apps) | A `docker-compose.yml`, started as written | no | no |

## Or start from a template

A [template](/guides/deploy/from-template) is a Compose stack from the catalogue, with passwords
generated and the address picked for you. Deplo creates a normal Compose app from it.

Open the catalogue from **Templates** in the sidebar, or from the **Template** button under the
five tiles in the new-app wizard.
