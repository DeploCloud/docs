A variable is `plain` or `secret` and applies to one or more `targets` (`production`, `preview`). A shared variable is owned by the team and **linked** into apps; the link is what injects it.

<Callout type="warn" title="A secret variable is write-only and immutable">
  Once a row is `secret`, `upsertEnv`, `renameEnv` and `saveSharedVar` refuse it, `setAppEnv` skips it, and `importEnv` counts it in `skippedSecrets` instead of writing over it. Rotating one is delete + create, and no mutation turns a secret back into a plain variable. The reverse (`plain` to `secret`) is always allowed.
</Callout>

### `upsertEnv`

Needs `manage_env`. Returns [`EnvVar`](/api-reference/types/objects#envvar).

Create or update an env var, then return the stored entity.

| Argument | Type | Description |
| --- | --- | --- |
| `input` | [`UpsertEnvInput!`](/api-reference/types/inputs#upsertenvinput) |  |
| `input.appId` | `String!` |  |
| `input.key` | `String!` |  |
| `input.targets` | [`[EnvTarget!]`](/api-reference/types/enums#envtarget) | One of `preview`, `production`. |
| `input.type` | [`EnvVarType!`](/api-reference/types/enums#envvartype) | One of `plain`, `secret`. |
| `input.value` | `String!` |  |

```graphql
mutation {
  upsertEnv(
    input: { appId: "prj_9f1c2ab7d3e4f5a6", key: "DATABASE_URL", value: "postgres://shop:secret@db-orders:5432/orders", type: secret, targets: [production, preview] }
  ) {
    id
    key
    type
    targets
    isMasked
  }
}
```

### `setAppEnv`

Needs `manage_env`. Returns `Int`.

Replace an app's whole env set from the .env editor (upsert the given entries, delete the rest). New vars default to plain; existing secrets are left untouched. Returns the resulting variable count.

| Argument | Type | Description |
| --- | --- | --- |
| `appId` | `String!` |  |
| `defaultTargets` | [`[EnvTarget!]`](/api-reference/types/enums#envtarget) | One of `preview`, `production`. |
| `entries` | [`[EnvEntryInput!]!`](/api-reference/types/inputs#enventryinput) |  |
| `entries.key` | `String!` |  |
| `entries.value` | `String!` |  |

```graphql
mutation {
  setAppEnv(
    appId: "prj_9f1c2ab7d3e4f5a6"
    entries: [{ key: "NODE_ENV", value: "production" }, { key: "PORT", value: "3000" }]
    defaultTargets: [production, preview]
  )
}
```

### `importEnv`

Needs `manage_env`. Returns [`EnvImportResult`](/api-reference/types/objects#envimportresult).

Bulk-import a .env-style blob. Every line lands as plain, so a key that already exists as a secret is skipped rather than downgraded.

| Argument | Type | Description |
| --- | --- | --- |
| `appId` | `String!` |  |
| `blob` | `String!` |  |
| `targets` | [`[EnvTarget!]`](/api-reference/types/enums#envtarget) | One of `preview`, `production`. |

```graphql
mutation {
  importEnv(appId: "prj_9f1c2ab7d3e4f5a6", blob: "API_URL=https://api.example.com\nLOG_LEVEL=info", targets: [production]) {
    added
    skippedSecrets
  }
}
```

### `saveSharedVar`

Needs `manage_env`. Returns [`SharedVar`](/api-reference/types/objects#sharedvar).

Create or update a shared variable; returns the saved entity.

| Argument | Type | Description |
| --- | --- | --- |
| `input` | [`SaveSharedVarInput!`](/api-reference/types/inputs#savesharedvarinput) |  |
| `input.appIds` | `[String!]` | The per-app links, as a whole set. OMIT to leave the existing links untouched - that is what preserves setSharedVarAppLink's app-side toggle. |
| `input.environmentIds` | `[ID!]!` |  |
| `input.id` | `String` |  |
| `input.key` | `String!` |  |
| `input.projectIds` | `[ID!]!` |  |
| `input.targets` | [`[EnvTarget!]`](/api-reference/types/enums#envtarget) | One of `preview`, `production`. |
| `input.teamIds` | `[ID!]!` | Teams every app of which gets this variable. ONE team => it is only SUGGESTED there and the per-app link injects (ADR-0012); TWO OR MORE => it is injected into every app of every one of them, with no link, at the lowest precedence. The caller must hold `manage_env` across the whole of every team named here. |
| `input.type` | [`EnvVarType!`](/api-reference/types/enums#envvartype) | One of `plain`, `secret`. |
| `input.value` | `String!` |  |

```graphql
mutation {
  saveSharedVar(
    input: { key: "API_BASE_URL", value: "https://api.example.com", type: plain, teamIds: [], projectIds: [], environmentIds: [], appIds: ["prj_9f1c2ab7d3e4f5a6"] }
  ) {
    id
    key
    type
    teamWide
  }
}
```
