## The installer

Written into `/opt/deplo/.env` and read by `docker compose --env-file`. Set
them in front of the install command.

<TypeTable
  type={{
    DEPLO_DOMAIN: {
      type: "domain",
      default: "empty, meaning a generated deplo-<hex>.nip.io host",
      description:
        "The domain the panel is served on. Must contain a dot, cannot be localhost, a .local name or an IP address. Either way the panel is served over HTTPS through Traefik, and the generated host stays routed alongside it.",
    },
    ACME_EMAIL: {
      type: "email",
      default: "admin@<the panel's own host>",
      description:
        "The Let's Encrypt registration email for that host's Traefik. Deplo reads the address back out of the running Traefik configuration, so there is no matching variable on the control-plane container.",
    },
    DEPLO_DB_PASSWORD: {
      type: "string",
      default: "generated, openssl rand -base64 24",
      description: "The Postgres password. Feeds both the database and the connection string.",
    },
    DEPLO_VERSION: {
      type: "image tag",
      default: "latest",
      description: "The image tag pulled: ghcr.io/deplocloud/deplo:<version>.",
    },
    DEPLO_SECRET: {
      type: "string",
      default: "generated, openssl rand -base64 48",
      description: "As above. Generated once and never rotated by a re-run.",
    },
  }}
/>

Four more the installer honours and nothing else reads: `DEPLO_SKIP_NET_CHECKS=1` to skip the
outbound reachability probes, `DEPLO_IMAGE` to install from a different image, and `DEPLO_TRACE` /
`DEPLO_LOG_FILE` for a verbose transcript. `DEPLO_DIR` moves the install directory off
`/opt/deplo`. The agent installer takes `DEPLO_TRACE` and `DEPLO_LOG_FILE` too.

## Notes worth reading before you change anything

<Callout type="warn" title="DEPLO_SECRET is permanent">
  Back up `/opt/deplo/.env`. See [Disaster recovery](/operations/disaster-recovery).
</Callout>

- **`DEPLO_SERVER_IP` must be a real, internet-reachable IPv4.** Generated
  hostnames encode it in hexadecimal, so a private or loopback address
  produces URLs that only work from that machine.
- **A hostname in `DEPLO_PUBLIC_URL` cannot seed a `nip.io` name**, so
  Deplo falls through to interface detection for the IP. Set
  `DEPLO_SERVER_IP` explicitly on a multi-homed box.
- **`DEPLO_DATA_DIR` is staging, not storage.** Nothing durable lives
  there.
- **Build-time placeholders exist in the Dockerfile** for the database URL
  and the secret. They never reach the runtime image and are not usable
  values.
