---
title: Networking
description: How traffic reaches an app, your own hostnames over HTTPS, and a URL per pull request.
---

Every hostname Deplo serves goes through the same router. Each hostname is
routed only after its DNS check passes. HTTPS uses Let's Encrypt when a real
domain is behind it, and plain HTTP on `deplo.site`.

**Domains and HTTPS** covers your own hostnames, certificates, path-based
routing and redirects. [Learn more ->](/guides/networking/domains-and-https)

**Automatic DNS** creates each domain's DNS record in Cloudflare for you, or
serves it through a Cloudflare Tunnel. [Learn more ->](/guides/networking/automatic-dns)

**Pull request previews** covers a temporary URL per open pull request, removed
when it closes. [Learn more ->](/guides/networking/pull-request-previews)
