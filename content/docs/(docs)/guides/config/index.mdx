Two kinds of configuration value, both encrypted, both typed `plain` or
`secret`, both injected at build time and at run time.

---

## How it works

**[Environment variables](/guides/config/environment-variables)** are set
directly on one app, with instance-wide and preview-only layers folding in
around them.

**[Shared variables](/guides/config/shared-variables)** are owned by the
team and linked into several apps at once, so one change reaches every app
that uses it.

A linked shared variable folds in above an app's own variable of the same
name. See [Environment variables](/guides/config/environment-variables) for
the full layering order.
