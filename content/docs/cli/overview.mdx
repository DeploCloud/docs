## Auth

<Accordions type="single">
  <Accordion title="deplo login">
    Authenticates the CLI with your Deplo account via the browser.
  </Accordion>
  <Accordion title="deplo logout">
    Clears the locally stored credentials.
  </Accordion>
  <Accordion title="deplo whoami">
    Prints the currently authenticated account.
  </Accordion>
</Accordions>

## Deployments

<Accordions type="single">
  <Accordion title="deplo up">
    Deploys the current directory. Detects the framework, builds, and
    returns a preview URL.

    ```bash
    deplo up --prod
    ```

    `--prod` deploys straight to production instead of creating a preview.
  </Accordion>
  <Accordion title="deplo promote">
    Promotes an existing deployment to production.

    ```bash
    deplo promote <deployment-id>
    ```
  </Accordion>
  <Accordion title="deplo rollback">
    Rolls production back to a previous deployment.

    ```bash
    deplo rollback --to <deployment-id>
    ```
  </Accordion>
  <Accordion title="deplo logs">
    Streams logs for the current or a given deployment.

    ```bash
    deplo logs --follow
    ```
  </Accordion>
</Accordions>

## Environment & config

<Accordions type="single">
  <Accordion title="deplo env">
    Manages environment variables. See [Environment Variables](/integrations/environment-variables).

    ```bash
    deplo env set KEY value --env production
    deplo env list --env production
    deplo env rm KEY --env production
    ```
  </Accordion>
  <Accordion title="deplo domains">
    Manages custom domains. See [Custom Domains](/core-concepts/custom-domains).

    ```bash
    deplo domains add example.com
    deplo domains status example.com
    ```
  </Accordion>
  <Accordion title="deplo link">
    Links the current directory to a Deplo project.
  </Accordion>
</Accordions>

<Callout type="info">
  Run `deplo <command> --help` for flags on any individual command.
</Callout>
