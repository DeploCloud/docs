Deplo has one API. The dashboard, the MCP server, your CI and your scripts all speak it.

```
POST  https://<deplo>/api/graphql      # the API
GET   https://<deplo>/api/graphql      # GraphiQL, in a browser
```

Every page in this section is generated from the live schema, so every query, mutation and subscription is here, each with who may call it, its arguments, and a working example.

---

## First call

Create a token under **Settings -> API tokens**, then:

```bash
curl https://<deplo>/api/graphql \
  -H "Authorization: Bearer deplo_xxxxxxxxxxxxxxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{"query":"{ me { username } apps { slug status } }"}'
```

```json
{
  "data": {
    "me": { "username": "ada" },
    "apps": [{ "slug": "shop", "status": "active" }]
  }
}
```

Read [Authentication](/api-reference/authentication) for the three credentials and how a request picks its team, then [Conventions](/api-reference/conventions) for what every operation has in common.
