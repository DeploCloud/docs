---
title: GitHub
description: Connect a repository and deploy on every push.
---

<Steps>
<Step>

### Install the GitHub app

Install the [Deplo GitHub App](https://github.com/apps/deplo) on your
account or organization, and grant access to the repositories you want to
deploy.

</Step>
<Step>

### Import the repository

```bash
deplo link
```

Run this from the repository root, or import it from the dashboard.

</Step>
<Step>

### Push

Every push to a connected branch now triggers a deployment automatically.

</Step>
</Steps>

## Pull request previews

<Callout type="success">
  Every pull request against a connected branch gets its own preview
  deployment, with a status check and a comment linking to it.
</Callout>
