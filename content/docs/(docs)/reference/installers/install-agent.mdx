The command the dashboard gives you under **Settings -> Servers -> Add server**:

```bash
curl -fsSL 'https://deplo.example.com/install-agent.sh' --output /tmp/deplo-agent-install.sh && echo '<token>' | sudo bash /tmp/deplo-agent-install.sh - 'https://deplo.example.com' '<fingerprint>'
```

<Callout type="warn" title="Always take this command from the dashboard">
  The panel fills the script in with the release's per-architecture download URL and checksum.
  The copy in the repository is a template and refuses to run.
</Callout>

<Callout type="info" title="Requires">
  Root, `systemd`, `curl` and `sha256sum`, on `linux/amd64` or `arm64`. Docker is installed if
  missing, except on a migration source, which needs the Docker it imports from. It refuses
  below **5 GB free on `/`**, warns below 30 GB, and checks nothing about memory or CPU.
</Callout>

## What the installer does

- Preflight: architecture, required tools, disk space, and whether the control plane's
  `/api/health` answers.
- Installs Docker, `git`, address pools and Traefik when the role needs them. Traefik is
  skipped when one is already running, or when `80` or `443` is taken (apps there stay
  unrouted until a proxy on the `deplo` network handles them).
- Downloads the `amd64` or `arm64` agent and refuses it unless its SHA-256 checksum matches.
- Writes `/var/lib/deplo-agent/bootstrap.env` (`0600`), the systemd unit and, except on a
  migration source, `/data/backups`, then starts the service. A reinstall first clears old
  certificates and saved panel addresses.
- IPv6-only: NAT64 and `deplo-clat`, as in the [panel installer](/reference/installers/install#ipv6).

The agent then calls home, sends a certificate signing request, and gets a signed
certificate. From then on it keeps a connection open to the control plane, which sends every
deploy over it. **The control plane never connects to your machine**, the agent opens no port,
and the installer never touches the firewall.

Logs: `journalctl -u deplo-agent -f`. Install transcript: `/var/log/deplo-agent-install.log`.
