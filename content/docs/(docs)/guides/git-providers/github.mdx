title: GitHub
description: Connect GitHub as a GitHub App, with nothing to copy and paste.
---

**GitHub** connects as a **GitHub App**. Deplo creates the App on GitHub for you, so there is no
client id or private key to copy. The App is installed where your repositories live, and mints
short-lived tokens to list and clone them.

## Connect it

<Steps>
<Step>

### Start the connection

**Settings -> Git**, then **Connect**, then **GitHub**. The new-app wizard's **Connect GitHub**
button opens the same menu.

</Step>
<Step>

### Choose account or organization

Pick **Personal account**, or **Organization** and type its name as in `github.com/acme`. Each
account or organization gets its own App: connect again for the next one.

</Step>
<Step>

### Approve and pick repositories

GitHub asks you to create the App, then to install it. Pick **All repositories** or **Only
select repositories**.

</Step>
</Steps>

To change the selection later, click **Manage** in the App's menu on **Settings -> Git**. With
**Only select repositories**, a new repository stays invisible until you add it there.

## What the App needs

A new App already has all of this. It matters only if someone narrows it later on GitHub:

| On GitHub | What it unlocks |
| --- | --- |
| **Metadata: Read-only** | See your repositories |
| **Contents: Read-only** | Clone your code to build it |
| **Subscribe to event: Push** | Deploy automatically when you push |
| **Pull requests: Read and write** | Post the preview address on the pull request |
| **Subscribe to event: Pull request** | Build a preview when a pull request opens |

The last two matter only for [pull request previews](/guides/networking/pull-request-previews).

When something is missing, **Deplo is missing access on GitHub** lists it on **Settings -> Git**,
on the app's **Settings -> Deployments** and on its **Pull requests** page, and the **Git provider
is missing access** alert fires. **Update on GitHub** opens the App's permissions page.

<Callout type="info">
GitHub holds changed permissions as pending until someone accepts them on each installation.
Accept them there too, or Deplo keeps reporting them as missing.
</Callout>

## Troubleshooting

| Symptom | What to check |
| --- | --- |
| **No repositories accessible to this App.** | Click **Configure repository access on GitHub**, or **Manage** on **Settings -> Git**, and add the repository. |
| **Deplo is missing access on GitHub** | The App lost a permission from the table above. Click **Update on GitHub**, then accept it. |
| **This repository will not clone** | The repository left the App's selection. **Manage** and add it back, or pick another App on the app's **Source** card. |
