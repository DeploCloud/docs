import { GitCommit, Workflow, GitPullRequest } from "lucide-react";

**Settings -> Git**, then **Connect**. It needs the `manage_git` capability.

- **GitHub** connects as a **GitHub App**: click, approve on GitHub, nothing to copy. See
  [GitHub](/guides/git-providers/github).
- **GitLab, Bitbucket, Gitea / Forgejo and plain Git** connect as a **git connection**, marked
  **Beta**: one stored token per host, your own instance included. See
  [Git connections](/guides/git-providers/git-connections).

Tokens are encrypted and never returned by the API.

## What each connection unlocks

| | GitHub App | GitLab, Bitbucket, Gitea | Plain Git, or a Repository URL |
| --- | --- | --- | --- |
| Repository picker and branch list | yes | yes | no |
| Deploy on push | yes | yes | no, use the [deploy hook](/guides/releases/automatic-deployments#the-deploy-hook) |
| Pull request previews and comments | yes | no | no |
| [Railpack](/guides/releases/build-settings#railpack) downloads past GitHub's anonymous limit | yes | no | no |

In the new-app wizard, GitHub has its own tile. Every other host is in the **Provider** menu of
the **Git** tile, which can also **Connect a git provider** on the spot.

## Good to know

- **One GitHub App per GitHub account or organization.** Connect once for each, so a personal
  account and an organization live side by side.
- **Connections are re-checked every 12 hours.** A revoked token, a GitLab token that expires
  within 7 days, or a lost permission raises the **Git connection stopped working** or **Git
  provider is missing access** [alert](/guides/observability/notifications-and-alerts), both on
  by default.
- **Push webhooks are registered for you**, and removed when no app deploys that repository
  anymore.
- **A token is per host, not per repository.** Limit its scope on the provider's side.

## Troubleshooting

| Symptom | What to check |
| --- | --- |
| **No repositories accessible to this App.** | Click **Configure repository access on GitHub** and add the repository. |
| `Authentication failed` in a clone | The token expired or was revoked. **Test connection** in the connection's menu confirms it. |
| Pushes do not deploy | The app's **Settings -> Deployments** shows **Deplo could not add the push webhook** with the reason. |
| `Address must not point at a private or internal address` | Only an instance admin can connect a host on a private network. |

More in [Deploys and builds](/troubleshooting/deploys-and-builds).
