---
title: Verify a domain
description: "POST /v1/domains/:id/verify"
---

```
POST /v1/domains/:id/verify
```

Re-checks DNS records and returns the updated [Domain object](/api-reference/domains).

```bash
curl -X POST https://api.deplo.build/v1/domains/dom_71cbe2/verify \
  -H "Authorization: Bearer $DEPLO_API_KEY"
```

<Callout type="warning">
  Returns `verified: false` with a `dns_record_missing` error detail if the
  required `A` or `CNAME` record isn't found yet. See
  [Custom Domains](/core-concepts/custom-domains) for setup instructions.
</Callout>
