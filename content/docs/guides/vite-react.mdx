Vite SPAs are static output, Deplo builds and serves the `dist/` directory
from its edge cache with automatic asset compression.

```bash
deplo up
```

## Client-side routing

<Callout type="warning" title="404s on refresh">
  If you use `react-router` in browser mode, refreshing a nested route
  returns a 404 unless you add a rewrite rule.
</Callout>

Add a `deplo.json` to rewrite every path to `index.html`:

```json title="deplo.json"
{
  "output": "dist",
  "rewrites": [{ "source": "/(.*)", "destination": "/index.html" }]
}
```

<Callout type="idea">
  This is only needed for client-side routing SPAs. Static multi-page sites
  and SSR frameworks handle routing on the server already.
</Callout>
