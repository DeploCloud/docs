---
title: Installation
description: Install the Deplo CLI on macOS, Linux, or Windows.
---

<Tabs items={['macOS / Linux', 'Windows', 'npm', 'bun']}>
<Tab value="macOS / Linux">

```bash
curl -fsSL https://deplo.build/install.sh | sh
```

</Tab>
<Tab value="Windows">

```powershell
irm https://deplo.build/install.ps1 | iex
```

</Tab>
<Tab value="npm">

```bash
npm install -g deplo
```

</Tab>
<Tab value="bun">

```bash
bun add -g deplo
```

</Tab>
</Tabs>

## Verify the install

```bash
deplo --version
```

<Callout type="warning" title="PATH not updated">
  If `deplo` isn't found after installing via the shell script, restart your
  terminal or re-source your shell profile (`~/.zshrc`, `~/.bashrc`).
</Callout>
