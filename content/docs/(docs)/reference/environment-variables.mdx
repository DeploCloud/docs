## Variables read by `install.sh`

Set them in front of the command, like
`curl -fsSL https://deplo.build/install.sh | DEPLO_DOMAIN=deplo.example.com bash`.

`DEPLO_SECRET`, `DEPLO_DB_PASSWORD`, `DEPLO_HOST_BOOTSTRAP_TOKEN` and `DEPLO_SETUP_KEY` are
not read from your shell: the installer generates them into `/opt/deplo/.env` (mode `0600`)
on the first run and never rotates them.

## Before you change one

<Callout type="warn" title="DEPLO_SECRET is permanent">
  Back up `/opt/deplo/.env`. See [Disaster recovery](/operations/disaster-recovery).
</Callout>

- **`DEPLO_SERVER_IP` must be a real, internet-reachable address.** Generated
  hostnames encode an IPv4 in hexadecimal and an IPv6 after `v6-`, so a
  private or loopback address produces URLs that only work from that machine.
- **A custom domain in `DEPLO_PUBLIC_URL` carries no IP**, so Deplo falls through
  to interface detection. Set `DEPLO_SERVER_IP` explicitly on a multi-homed box.
- **Build-time placeholders in the Dockerfile** (database URL, secret) never
  reach the runtime image and are not usable values.
