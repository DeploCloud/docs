Every app starts from one of four sources. Pick the one that matches what you already have.

---

## The four sources

| Source | What it needs | Builds an image | Rollback |
| --- | --- | --- | --- |
| [Git](/guides/deploy/from-git) | A repository, connected once per team | yes | yes |
| [Docker image](/guides/deploy/docker-image) | An image reference | no, already built | no |
| [Template](/guides/deploy/from-template) | Nothing, pick one from the catalogue | yes, it is a Compose stack | no |
| [Upload](/guides/deploy/upload-code) | A compressed archive of the project | yes | yes |
